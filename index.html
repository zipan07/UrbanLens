URBANLENS STUDIO 19.0

城市更新用地
智能评估交互系统

以南京市玄武区为研究范围，汇集真实开放地图、建筑轮廓、道路、水系、公共设施与地形数据。地图风格由 UrbanLens 设计。

建筑高度分为 OSM 标注、楼层推算和缺失示意；本版没有接入高德底图、正射影像或倾斜摄影模型。开放地图不是法定地籍与规划成果。

DeepSeek 接入暂缓。主界面已集成五维评估、单元比较、参数化容量情景、带来源对话与DOCX报告。完整演示模式叠加虚构业务台账；公开数据模式保留缺失，不输出伪综合分。

 NAVIGATION / 跨端操作

用熟悉的方式探索。

Mac 触控板

Safari：双指扭转调整方向，捏合缩放。
其他浏览器：按住 ⌥ Option，双指滑动旋转。普通双指滑动保持原有地图操作。

Windows 鼠标

按住中键拖动旋转；3D 下上下拖动调整俯仰。滚轮缩放，左键拖动平移。

手机 / 平板

双指捏合缩放，双指扭转旋转。也可点击地图右下角的方向按钮。

键盘与快捷操作

Q / E 左右旋转 · N 指北针 复位方向
⌘ / Ctrl K 快捷命令 · ? 打开本指南
全屏模式下 Esc 返回工作台；操作地图会暂停环绕播放。

浏览器对触控板手势的支持不同；未提供扭转事件时，请使用 Option 滑动或方向按钮。
