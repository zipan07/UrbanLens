# UrbanLens UI font

`urbanlens-grotesk-latin.woff2` is a locally hosted Latin/number subset of the Space Grotesk 2.0 variable font by Florian Karsten / the Space Grotesk Project Authors. The font is licensed under SIL Open Font License 1.1; the complete original notice is in `SpaceGrotesk-OFL.txt`.

Official upstream: https://github.com/floriankarsten/space-grotesk

Source file: https://github.com/floriankarsten/space-grotesk/blob/master/fonts/woff2/SpaceGrotesk%5Bwght%5D.woff2

Retrieved 2026-09-12. The subset retains 225 supported characters from U+0020–00FF, U+2000–206F, U+20AC, U+2190–2193, U+2212, U+221E, with the original variable weight axis 300–700 and OpenType layout features. The internal family/full/PostScript names have been changed to UrbanLens Grotesk / UrbanLens Grotesk Regular / UrbanLensGrotesk-Regular to distinguish this modified subset. Original copyright and license metadata are retained.

Source SHA-256: `8e085aa438094f11487a836652edd5c054fa6a96f63fc7c282105ee3a4b08c07`

Subset SHA-256: `9f4f7e58e1fc7f19677056e6bcd98a05699c284b62f05ad004f1e62e64e23601`

Subset generated with fontTools 4.61.1 and Brotli 1.2.0. File size: 19,972 bytes. Chinese characters intentionally use system PingFang SC / Microsoft YaHei / Noto Sans CJK SC fallbacks, so the small web font never limits map labels or Chinese user input.

```css
@font-face {
  font-family: "UrbanLens Grotesk";
  src: url("./fonts/urbanlens-grotesk-latin.woff2") format("woff2");
  font-style: normal;
  font-weight: 300 700;
  font-display: swap;
}
```
