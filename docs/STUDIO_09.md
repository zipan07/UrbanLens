# Studio 09 · 南京六区与地图详情

2026-09-12。制作者：东南大学建筑学院 蔡子攀。

## 本版变化

研究范围从玄武区扩展至鼓楼、玄武、秦淮、雨花台、建邺、栖霞六区。行政区菜单与命令面板可定位对应城区，并同步筛选研究单元和地图搜索结果。全城视角显示六区范围；玄武湖、四牌楼和当前研究单元视角继续保留。

界面改为白色与浅灰蓝色为主，中英文正文、标题、按钮和数值整体放大。浮动工具栏、地图控制、按钮、卡片及详情面板采用圆角、半透明背景、柔和阴影和背景模糊，强调简洁、清晰的产品质感。字体优先使用设备系统字族；部分拉丁字体仍由站点本地提供。背景模糊效果受浏览器支持和性能影响。

## 地图上查看详细信息

| 操作 | 结果 |
| --- | --- |
| 左键点击用地、道路或建筑 | 选中空间对象并显示对应档案；研究单元可进入原有用地研究流程。 |
| 在地图对象上单击右键 | 在地图内打开该位置的详情卡，展示类型、名称、可用属性与来源。 |
| 同一位置有多个对象 | 在详情卡中切换候选对象，区分覆盖在一起的研究范围、建筑、道路或用地。 |
| 触屏长按地图对象 | 打开就地详情；实际手机触摸体验仍需实机验证。 |
| 从详情卡打开档案或定位 | 进入完整档案或聚焦当前对象；可导出对象 GeoJSON。 |

建筑高度区分 OSM 标签、楼层推算和缺失示意；道路按实际标签展示等级及可用属性，未记录的信息保持未知。用地轮廓仍是研究参考范围，不当作登记宗地。对象信息的精度与完整性受开放地图来源限制。

旋转操作保留 Windows 鼠标中键拖动、Mac Safari 原生双指扭转、其他 Mac 浏览器 Option + 双指滑动，以及 Q / E 和屏幕旋转按钮。触屏双指操作继续由地图处理。兼容模式使用同一数据的 Canvas 2D，不能显示真实三维俯仰和地形。具体手势说明亦见 [STUDIO_08.md](STUDIO_08.md)，其旧版视觉验收记录不适用于本版新界面。

## 数据与价值研究

本次实际下载六区 OSM 数据，经原始对象 ID 去重后，收录 46,515 个建筑及部件、29,994 个道路等线对象、6,743 个用地等面对象、999 个水体、4,071 个具名 POI 和 4,395 个服务参考点。新增研究范围后共 28 个单元，原 `XW-R01` 至 `XW-R08` 编号保留；新增区各提供四个真实轮廓示例。

五维评估、权重情景、比较、来源对话、业务 CSV 关联、容量假设和含地图的 DOCX 报告继续沿用原有流程。公共数据模式保留业务缺失项，不输出缺乏依据的综合分；完整演示中的业务属性明确标为虚构。真实轮廓列入清单，不表示被认定为低效或拟实施更新。

六区空间数据不等于六区业务资料已完整接入：既有五篇案例与规划资料、两笔历史土地成交参考仍主要涉及玄武区；权属、法定规划条件、空置与经营台账等仍待接入。同站地形仍覆盖原玄武区及邻近范围，没有新增全六区卫星影像、建筑精模或倾斜摄影。完整来源和原始几何限制见 [NANJING_DATA.md](NANJING_DATA.md)。

## 加载与数据下载

空间层采用无损 gzip 分块，约 7.7 MB，分块文件名包含内容哈希。浏览器解压后使用完整几何及属性，没有为了减小下载而删减数据；数据目录可从内存下载原始 GeoJSON。运行时不依赖 Overpass 查询或外部底图服务器。构建及发布说明见 [GITHUB_PAGES.md](GITHUB_PAGES.md)。

## 验证状态

当前 56 项自动测试通过，覆盖六区边界与数据计数、研究单元、来源与高度缺失、导入、价值评估、对象拾取及原有报告和交互逻辑。独立数据 QA 核对了分区统计、唯一 ID、研究单元与源几何的一致性，以及设施合并来源数量；已知原始建筑面的少量自交问题保留并记录在数据说明中。

Studio 09 的线上桌面与窄屏视觉检查仍待完成，不能沿用 Studio 08 的检查结果宣称已完成本版视觉验收。真实 GPU 三维渲染、Windows 中键硬件、Mac 触控板原生手势及手机长按、双指操作仍需相应设备验证。自动事件测试与静态布局实现不等于这些实机检查通过。

历史 `demo.html` 及旧版本文档继续保留。DeepSeek 仍暂缓；本版对话使用本机确定性检索，不调用模型服务。

## Apple 视觉细化

地图参考 Apple Maps 的浅色水系、柔和绿地、道路层次和浮动工具；工作台采用白色底、黑灰文字、少量蓝色动作及克制毛玻璃。删除地图大标题、版本徽章及装饰性英文，压缩主要文案。字体优先调用 Apple 系统已有 SF / 苹方，其他设备回退 Helvetica Neue / Arial / 微软雅黑；不分发 Apple 字体文件，跨系统显示不会完全相同。字体来源说明：https://developer.apple.com/fonts/ 。
