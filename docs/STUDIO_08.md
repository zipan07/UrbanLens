# Studio 08 · 路演视觉与地图交互

2026-09-12。制作者：东南大学建筑学院 蔡子攀。

## 视觉与演示

深色背景配合青柠、冷紫与冷白文字，强化地图、当前对象、关键数值和操作入口的层级。拉丁字母与数字使用本地托管的 UrbanLens Grotesk（Space Grotesk 子集，约20KB，SIL OFL 1.1），中文使用 PingFang SC / Microsoft YaHei 等系统字族。字库来源与许可见 [fonts/README.md](../dist/fonts/README.md)。

参考 [TestFit 官方平台](https://www.testfit.io/) 与 [Giraffe 官方平台](https://www.giraffe.build/) 的地图中心布局、空间视角和集成工作流。界面为 UrbanLens 独立实现。

- **命令面板**：⌘ / Ctrl + K 打开，按名称搜索研究单元、评估、对话、比较、报告、数据或视角；方向键选择，Enter 执行，Escape 关闭。
- **路演模式**：展开地图，按需显示研究面板，保留制作者标签；可通过退出按钮或 Escape 返回。
- **视角预设**：玄武全域、玄武湖畔、四牌楼片区及当前研究单元。
- **环绕播放**：手动开启或暂停；地图操作、离开页面和退出路演会停止播放。系统启用“减少动态效果”时不启动环绕。
- **视角保存**：将位置、缩放、方位与俯仰保存在当前浏览器，再按“恢复视角”调用。

## 地图操作

| 设备 / 输入方式 | 操作 |
| --- | --- |
| Windows 或其他桌面鼠标 | 按住中键左右拖动旋转；已有3D倾斜视角下，上下拖动调整俯仰。2D视角保持平面。 |
| Mac Safari 触控板 | 双指扭转旋转；双指捏合缩放。依赖浏览器提供原生 GestureEvent。 |
| 其他 Mac 浏览器 | Option + 双指滑动旋转。Chrome / Firefox 不向网页提供触控板原生扭转角度，因此使用这一兼容手势。 |
| 手机 / 平板触屏 | 保留地图原生双指旋转、缩放与平移。 |
| 键盘 / 屏幕按钮 | Q / E 或旋转按钮，每次调整15°；输入框与对话框内不触发地图快捷键。 |

普通滚轮和捏合缩放仍由地图处理。中键释放、窗口失焦及页面隐藏会结束旋转状态。地图无图形加速时使用 Canvas 2D 兼容模式，俯仰固定为0。

## 数据与评估

沿用 Value Studio 07 的研究范围、设施参考点、公开案例与历史成交参考。本轮聚焦视觉和交互，没有新增数据采集或改变评估规则。五维评估、比较、来源对话、报告导出与本机历史记录继续使用原有流程。DeepSeek 保持暂缓。

公共数据缺失项、虚构演示台账、研究轮廓与登记宗地的区别继续明确显示。完整功能与来源边界见 [VALUE_STUDIO.md](VALUE_STUDIO.md)。
