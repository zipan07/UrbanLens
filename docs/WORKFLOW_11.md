# Studio 11 · 工作台操作闭环

本轮对应升级计划第一步，以“筛选—选地—评估—查依据—比较—导出”为验收路径。保留白色玻璃界面、黑灰银环形标识和双单位署名；继续使用既有玄武区底座。

## 本轮范围

| 环节 | 调整 | 验收要点 |
| --- | --- | --- |
| 筛选 | 关键词、行政区、用途、面积、评估状态、独立资料完整性、仅看当前视野 | 内置及导入研究范围使用同一筛选规则；地图与列表结果一致，组合条件与重置有效 |
| 档案 | 右键详情与完整对象档案统一几何指标、来源及标签 | 道路长度、面对象面积等已展示信息进入完整档案后保留；不同对象切换不残留前一个对象内容 |
| 缺失值 | 交通距离为空时明确展示缺失，合法零值保留 | 比较、界面和报告不会把无数据解释为零距离 |
| 比较 | 对缺失数据、未评估及口径不一致提供明确提示 | 条件不满足时不输出误导性的综合排序；支持返回补资料或统一重评 |
| 报告 | 内容不变时复用已保存报告，重复下载和打印不新增版本 | 连续下载 / 打印历史数量稳定；真正修改叙述生成新记录，旧报告不被覆盖 |
| 能力说明 | 更新首页发布说明，明确旧样例边界 | 首页 GIS 导入、DOCX 与本机历史不再被旧样例说明误写为全站未实现 |

资料完整性仅表示评估字段的有效覆盖，不代表规划、权属、安全资料已正式核验。行政区筛选只列当前载入资料中的行政区，不代表六区扩展已经完成。当前视野筛选只限制研究范围清单，不移除底图建筑、道路等背景图层。

## 验收路径

1. 在首页组合关键词、行政区、用途和面积条件，核对清单与地图；使用资料完整性与评估状态分别筛选，并确认重置。
2. 开启仅看当前视野，移动或缩放地图，核对结果跟随；载入含多个研究范围的 GeoJSON 后重复筛选并移除。
3. 选择道路与面对象，比较右键卡片、完整档案中的长度 / 面积及标签；切换对象确认档案刷新。
4. 对数据不完整、尚未评估、评估口径不同的单元执行比较，核对提示和排序限制；统一重评后检查结果。
5. 运行评估并生成报告，连续下载 DOCX、Markdown 和打印，检查历史版本复用；修改叙述后确认新增记录和旧记录保留。
6. 打开历史样例，确认页面和本地知识助手均说明其为 12 宗虚构地块旧版，并指向首页当前能力。
