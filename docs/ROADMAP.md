# UrbanLens 升级路线 / Studio 13

本路线对照 V0.1 PRD。Studio 11 先补齐现有工作台的操作闭环，随后依次建设项目基础、证据与报告、南京六区底座、证据助手及专业验收。当前前端仍是面向研究与路演的演示工作台，不能视为完整业务系统交付。

## 第一步：现有操作闭环

本阶段覆盖关键词、行政区、用途、面积、评估状态、独立资料完整性与当前视野筛选，统一地图与列表结果；统一右键详情与完整档案；修正交通距离缺失显示、比较口径提示与报告版本重复；清理旧样例对当前平台能力的过时说明。

验收路径：“筛选—选地—评估—查依据—比较—导出”。同一字段、评估状态与报告版本应在不同界面保持一致。实现及验证记录见 [WORKFLOW_11.md](WORKFLOW_11.md)。

## 分阶段建设

2. **项目、数据与历史版本。** 建立项目列表、新建、进入和归档，使边界、台账、附件、评估与报告归属项目；补全导入预检、字段映射和冲突处理，接入后台存储及管理员、编辑者、查看者权限。验收时刷新与更换设备后项目完整，旧结果可追溯，未授权项目不可访问。
3. **评估依据与报告。** 保存指标原始值、单位、日期、来源和有效状态；独立展示规划、权属、安全约束；增加规则适用范围、复核和待重算提示。引入 PDF / TXT 与页码定位，统一档案、问答、比较、报告证据。以至少 10 个独立样本复核计算，并验证办公软件中的 DOCX。
4. **南京核心六区。** 逐步增加鼓楼、玄武、秦淮、雨花台、建邺、栖霞的行政切换、分区数据和代表性研究单元。底图整理可并行，但业务可评估性单独核实；详细建筑按范围和缩放加载，逐区展示来源、覆盖与缺失。
5. **证据助手，再接 DeepSeek。** 优先完善资料相关性、无匹配说明、精确引用、自定义编号及可编辑筛选提议；项目权限、资料检索与操作接口稳定后再接入主站大模型。至少 20 道问题覆盖事实、解释、资料和无依据场景；模型不可用时仍能评估和导出。
6. **性能与专业验收。** 按 1,000 宗地块、5 位同时在线用户的 PRD 基线验证；补 Chrome / Edge 指定分辨率、真实 GPU、Mac / Windows 手势及地图失败后的列表访问。邀请 3 名专业使用者独立完成全过程，以卡点、耗时和返工情况调整。

六区扩展不属于第一步已交付内容；地图筛选中的行政区选项仅来自当前实际载入的资料。现有建筑、道路、设施和研究轮廓不等于官方地籍或调查台账，演示评分不能替代正式评估。
