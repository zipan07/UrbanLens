# UrbanLens V0.1 开发路线

## 本轮交付

本轮是 PRD 的首个交互切片，不是全部 P0 功能的实现。英文品牌确定为 UrbanLens；中文正式名称保留“城市更新用地智能评估交互系统”。

| PRD 功能 | 当前切片 | 后续工作 |
| --- | --- | --- |
| F01 项目及数据导入 | 一个虚构片区和12宗内置地块 | 字段字典、坐标系约定、真实文件导入与批次预检 |
| F02 地图与档案 | 材质与光影三维城市、六类图层、建筑档案、面积/评估/完整性筛选 | 真实底图、行政区与当前视野筛选、数据版本 |
| F03 多维评估 | 五维演示计算、缺失值控制、会话内运行快照和来源说明 | 正式指标、发布配置、独立业务复核 |
| F04 AI交互 | 范围隔离的证据检索、问答历史、DeepSeek代理及引用校验 | 真实模型部署联调、向量检索、文档导入与用户权限 |
| F05 地块比较 | 2–3宗同规则比较 | 数据时点和规则版本不一致处理 |
| F06 报告 | 当前地块摘要、Markdown与打印；独立高清地图PNG | DOCX、报告历史、复核流程及地图自动入报 |
| F07 管理 | 无账号，页面内存演示 | 组织、项目隔离、权限、审计和持久化 |

## 下一阶段

1. 与使用者走通“筛选—选地—评估—依据—比较—报告”，确认交互与信息密度。
2. 确定试点用地类型、数据负责人和授权数据清单；形成GeoJSON与属性字段契约。
3. 发布可复核的指标规则样例，替换任意演示阈值和标签。
4. 确定后台部署方案，建立项目、地块和评估运行的数据模型。
5. 最后接入资料检索与模型服务，保持确定性计算与语言解释分工。

## 本轮验证

自动验证：22项测试（评分、联合筛选、几何约束、正逆投影、WebGL相机与二维标签对齐、建筑实例矩阵、兼容绘制调用）、构建与JavaScript语法、HTML本地资产引用。

尚待验证：DeepSeek真实模型联调、手机真机双指操作、实际GPU着色器执行、浏览器视觉与交互、高清PNG下载、打印版式、移动端和200%文字缩放、真实地理数据性能、真实用户试用。WebMCP为渐进增强；当前环境未进行受支持浏览器上下文中的注册与执行验证。

## 演示规则

五个维度各20%。空间布局采用到设施的虚构直线距离；利用效率采用任意容积率基准2；产业标签及建筑等级均为虚构台账值；使用状态采用虚构空置率。高分代表更应研究的关注度，不代表适合开发或投资。所有维度有效时才合成综合分。详细映射见 `dist/domain.js` 与界面“计算依据”。

这些阈值不是国家、行业或地方标准，也不是产品最终模型。

Atlas 06 验证补充：新增真实数据 Canvas 2D 兼容渲染，保留移动手势与资料访问；无GPU时明确禁用3D/地形。28项自动检查及桌面/390px窄屏交互检查已完成。真实城区 WebGL 3D 与实体手机多点触摸仍待硬件环境验证，不能将样式通过视为完整实机验收。
