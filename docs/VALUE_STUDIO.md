# Value Studio 07 用地研究演示

制作者：东南大学建筑学院 蔡子攀。

本轮把PRD中的评估、解释、比较与报告迁入玄武区真实地图。默认“公共数据”保留未知业务字段，不计算综合分；“完整演示台账”在真实轮廓上使用虚构业务属性，展示五维更新研究关注度。分数不是土地市场价值，研究轮廓不是登记宗地或官方更新范围。

## 演示路径

1. 首页点击“开始完整演示”，选择创意中央产业园研究单元。
2. 运行五维评估，查看原始值、来源、缺失控制与三套演示权重。
3. 进入来源对话，追问原因、配套或缺失项；切换对象后历史消息保留原对象标签。
4. 比较2–3个研究单元，统一口径重评；规则、模式、日期不一致或有缺失时不排序。
5. 生成含研究地图的报告，填写研究叙述和本机演示复核意见，保存版本并导出DOCX、Markdown或打印。

另可使用容量假设面板调整容积率、保留比例和公共空间比例；它只计算面积情景，不预测收益或判断规划许可。历史12宗虚构地块和旧版交互仍可从历史样例入口访问。DeepSeek暂缓，首页对话为确定性来源检索与动作提议，不调用模型。

## 数据与口径

- 地图底座沿用Atlas 06：玄武区OSM边界、建筑、路网、水系、用地和DEM，详见XUANWU_DATA.md。
- 8个研究单元来自已有OSM面：创意中央产业园、1912、锁金四村、红山机电花园、徐庄软件园研发一区、福中高科技产业园、徐庄文化中心、东南大学四牌楼校区。
- 设施快照2026-09-12T02:20:24Z；原始4,340条，分类2,885条，按同类同名80米内合并后2,697个参考点：交通654、教育331、医疗83、公园138、历史186、生活服务1,305。查询范围覆盖玄武及邻近地区，支持跨界配套观察。
- 面对象使用包围盒中心，点位不是入口。600米观察圈及最近设施采用研究代表点的直线距离，不是步行路径、可达时间、开放状态或容量。分组合并保留相关OSM编号，但不构成完整设施普查。
- 面积按WGS84转UTM 50N计算并扣除孔洞；建筑参考数以主体对象包围盒中心落入轮廓筛选，不是法定建筑栋数。
- 5条南京市政府公开案例/政策与2条历史成交参考，逐条链接、日期、局限见dist/data/value-evidence.json。成交原站正文暂不可达，只核对到官方搜索索引；不能作为现行估价依据。
- 白子亭公开建筑面积为总建筑面积，未确认计容口径，不据此推导正式容积率；长江路片区客流销售额不分摊到研究单元。
- 未取得权属、法定规划条件、红线约束、现状计容面积、空置率和建筑调查等授权台账。缺失保留为空，不按零处理。

抓取与整理脚本：scripts/fetch-value-services.py、scripts/prepare-value-data.mjs。OSM数据遵循ODbL 1.0并保留署名。坐标投影采用proj4，DOCX使用fflate封装OOXML；依赖许可见THIRD_PARTY_NOTICES.txt。

## 计算和本机数据

五维规则沿用DEMO-0.1：空间布局、利用效率、产业结构、建筑品质、使用状态。容积率基准2等阈值均为任意演示参数，高分仅表示更应研究的关注度。三套权重具有独立版本；100%有效指标加权覆盖才输出综合分。覆盖率表示字段有效性，不代表事实可信度。

CSV按parcel_id关联；字段为building_area_m2、vacancy_pct、industry、condition、source、date。空值保留、合法0有效；非法范围、日期、重复或孤立编号整批拒绝，来源必填。上传内容标为“用户台账待核实”。

评估运行保留输入、规则、来源时间和结果快照；对话动作引用当前业务函数，旧上下文动作失效。浏览器localStorage最多保存80次评估、30条消息、8份报告。清理浏览器数据会删除本机历史；不具备云端项目、账号权限、组织隔离或正式审批。

## 验证范围

42项自动测试已通过，覆盖投影面积、配套数据一致性、缺失和合法零值、权重、比较口径、CSV原子校验、对话范围、报告OOXML与既有地图样式。构建和JavaScript语法检查通过。

上线前检查桌面与390像素窄屏的核心演示流程。测试浏览器禁用GPU，只能验证Canvas 2D兼容模式；真实3D视觉及实体手机多点触摸需在支持图形加速的设备继续验收。本轮没有将完整PRD或真实业务评估标为验收通过。

发布资源按gzip小块保存于dist/packed，前端并行读取、校验解压后运行；避免连接器单次大文件上传超时。业务数据下载仍生成完整GeoJSON。npm run build可从保存的压缩数据恢复设施源文件并重建资源。

2026-09-12线上验证：桌面五步引导、公开数据20%覆盖不合成、演示50.6分、三单元比较、报告填写和保存、DOCX生成操作，以及390px工作台与切换单元后的对话标签已检查。报告已保存后重开仍有复核文本。DOCX文件结构有自动检查，尚未完成Word各版本和分页排版兼容验收。
