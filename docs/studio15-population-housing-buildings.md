# Studio 15: 人口、住宅样本与建筑外观

地图图层可选夜间 / 白天人口；评估步骤 2、3 显示片区汇总，含自定义 Polygon/MultiPolygon 和孔洞。

人口格网全部为模型情景：2023 年玄武区官方常住人口 536900 人仅用于夜间总量校准，按 OSM 居住用地与建筑权重分配到 366 个 500m 裁切网格。白天暂设夜间总量的 1.15 倍，40% 居住与 60% 就业设施权重。这不是实时或手机信令观测。来源、参数与限制见 `dist/data/population-metadata.json`。WorldPop 仅核对官方 API 总量，未取得其栅格，不用于当前图层。

住宅数据通过有编辑权限的项目导入 CSV，字段：

`id,name,lng,lat,kind,basis,price,area_m2,source,url,date`

- 坐标为 WGS84 南京范围；area_m2 为建筑面积平方米。
- kind=sale 时 price 为总价万元；kind=rent 时为元/月。
- basis=asking 为挂牌，transaction 为成交；禁止混合统计。
- date 为 YYYY-MM-DD，url 为原始 HTTPS 链接；保留来源、日期及用户提供待核实标记。
- 先取片区内样本，无则取距边界 600m 内样本，按同类型中位数统计；同一链接仅采用最新记录。
- 导入有预检、字段映射、整条来源冲突选择与不可变数据版本；查看者不能导入，未授权项目返回 404。

贝壳租售页面本次返回人机验证，未取得可核验记录。当前没有接入实时贝壳 API。可在取得使用授权后导入样本，或按官方开放平台合同接入。缺样本时仅混合 / 演示模式使用明确标为 UrbanLens 的稳定模拟值，绝不标成贝壳价格。

辅助权重 UI 默认 20%，可关闭或设为 0–30%。保留基础五维分，辅助分是人口密度分与住宅售租价格分的均值；合成公式为 `(1-w) × 基础分 + w × 辅助分`。人口基准 20000 人/km²、售价 60000 元/m²、月租 120 元/m² 均为未经校准的实验阈值。高辅助分表示人口与住宅市场强度高，不等于地价、投资收益或更新优先级。严格数据模式缺辅助依据时有效权重归零。服务端重新计算，不信任客户端分值。

配置、人口版本、采用样本、原始链接及日期冻结在运行、比较和报告中；新版本不覆盖旧运行，不同辅助口径不可排序。

所有已收录 3845 个建筑和部件有显示高度：保留 187 个 OSM 高度、94 个楼层推算；3564 个缺高度对象根据类别、轮廓、街区与邻近标注稳定推算。显示高度不写入原始 height_m，也不用于修改业务建筑面积。图层中的“外立面与平 / 坡屋顶”默认关闭，开启后在 3D 放大视图显示程序化窗格、玻璃、平顶、坡顶与地标材质提示，并非照片贴图或精确复原。每视野至多 420 栋、150000 顶点；2D、关闭建筑、关闭估高和换主题时正确清理 / 重建。

复现人口：安装 shapely/pyproj 后运行 `python scripts/generate-population.py --out-dir dist/data`。验证：`npm test`；构建：`npm run build`。
