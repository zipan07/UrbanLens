# UrbanLens · 玄武用地价值研究 / Studio 11

城市更新用地智能评估交互系统。制作者：蔡子攀｜东南大学建筑学院 · 东南大学城市规划设计研究院。

[打开 UrbanLens 工作台](https://zipan07.github.io/UrbanLens/)

Studio 11 对照 V0.1 PRD，先补齐“筛选—选地—评估—查依据—比较—导出”的操作闭环：补全联合筛选，统一地图与档案信息，修正缺失值和比较状态提示，使重复下载、打印复用已保存报告。本阶段范围和验收记录见 [WORKFLOW_11.md](docs/WORKFLOW_11.md)，后续升级步骤见 [ROADMAP.md](docs/ROADMAP.md)。这次升级不代表全部 PRD 已完成。

## 当前工作台

- 玄武区真实开放地图，8 个真实轮廓研究单元及 2,697 个周边设施参考点；支持 2D / 3D、图层、定位、测距和地图导出。
- 关键词、行政区、用途、面积、评估状态、资料完整性与当前视野联合筛选；地图和列表使用同一研究清单，内置与导入范围共同参与。
- 地块、建筑、道路等对象可在地图中选择、右键查阅和进入档案；几何指标与标签保持一致。
- 五维确定性评估、三套演示权重、来源解释、2–3 个研究单元比较、容量假设与含地图的 DOCX / Markdown 报告。点击“开始完整演示”可顺序体验。
- GeoJSON 研究范围导入与 CSV 台账关联。报告、评估、对话历史和保存的视角保存在当前浏览器；导入边界仍为会话数据，刷新后清除。
- 首页证据助手采用本机确定性检索；DeepSeek 暂缓，主站没有调用大模型。

默认公共数据模式保留未知业务字段，不输出综合分。完整演示台账含明确标识的虚构属性，仅用于演示研究关注度，不代表真实土地价格或项目可实施性。研究轮廓不是登记宗地或官方更新范围；完整性筛选指评分字段是否有效，不代表规划、权属与安全资料已核验。

本阶段保留玄武区底座，南京核心六区扩展、服务端项目保存、账号权限、正式规则和业务复核仍在后续阶段。数据及演示边界见 [VALUE_STUDIO.md](docs/VALUE_STUDIO.md) 和 [XUANWU_DATA.md](docs/XUANWU_DATA.md)。

## 界面与地图操作

延续白色工作台、浅色地图、通透玻璃和黑灰银五瓣环形标识，保留双单位署名、命令面板和路演模式。字体优先使用设备已有的 SF / 苹方及系统回退字族，不分发 Apple 字体。设计记录见 [LIQUID_10.md](docs/LIQUID_10.md) 和 [RING_MARK_10_3.md](docs/RING_MARK_10_3.md)。

鼠标中键按住拖动旋转；已有 3D 倾斜视角下，上下拖动调整俯仰。Mac Safari 支持触控板双指旋转；其他 Mac 浏览器可用 Option + 双指滑动。触屏保留原生双指操作，并提供 Q / E 和屏幕旋转按钮。支持图形加速时使用 MapLibre 2D / 3D 与真实地形；不可用时回退到同数据的 Canvas 2D。硬件和浏览器支持边界见 [STUDIO_08.md](docs/STUDIO_08.md)。

## 本地运行与验证

使用 Node.js 22 或更高版本，依赖版本已锁定。前端使用可检查的 UTF-8 JavaScript 分块；修改 `src/` 后需要重新构建：

```sh
npm ci
npm run build
npm start
```

打开终端显示的 HTTP 地址；浏览器 ES 模块不能直接通过 `file://` 运行。验证命令：

```sh
npm run check
npm test
```

自动测试覆盖确定性计算、缺失值、筛选、报告及地图数学等逻辑。测试通过不等于完成真实 GPU、实体设备手势或专业使用者验收；当轮实际结果与限制记录在发布文档中。

## 目录

- `src/atlas-app.js`：首页地图与对象档案。
- `src/value-studio.js`：研究工作台、比较、问答及报告交互。
- `src/value-domain.js`、`src/value-report.js`：评估规则、输入契约与报告生成。
- `dist/`：可独立托管的前端、已构建运行文件与静态资产。
- `dist/demo.html`：历史 Metro 05 样例，含 12 宗虚构地块；不代表当前首页能力。
- `docs/PRD-v0.1.md`：产品需求基线，不代表全部实现。
- `docs/ROADMAP.md`：当前功能边界和分阶段升级步骤。
- `test/`：Node 内置测试工具运行的自动测试。

## 历史样例与开发约定

`demo.html` 保留首轮虚构城市与 `DEMO-0.1` 规则，用于回看旧交互。该页只提供会话内评估、Markdown 摘要和打印；地图是程序化虚构模型，与玄武区没有地理关联。其知识助手与后端代理属于旧样例，不能视作主站模型服务。当前 GIS 导入、含地图 DOCX 和本机报告历史请使用首页。

通过功能分支与 Pull Request 发布，GitHub Pages 为现有托管渠道。不提交 API 密钥或环境凭据；私有业务台账与公开空间数据分别管理。演示规则与正式规则保持明确区分。DeepSeek 后端参考见 [DEEPSEEK.md](docs/DEEPSEEK.md)，实际接入继续后置。
