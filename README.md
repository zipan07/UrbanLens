# UrbanLens · 玄武用地价值研究 / Studio 10

城市更新用地智能评估交互系统。制作者：东南大学建筑学院 蔡子攀。

Studio 10 在白色工作台与浅色地图上细化玻璃材质和交互动效：透明工具栏、边缘高光、快速按钮反馈、滑动选项底板、面板过渡及可打断的地图定位。长文本和评估内容保持清晰白底，移动端采用更宽的搜索栏与独立地图工具行。字体优先使用设备已有的 SF / 苹方和系统回退字族，不分发 Apple 字体。命令面板、路演模式和原有评估流程继续保留。

地图支持鼠标中键按住拖动旋转；已有3D倾斜视角下，上下拖动调整俯仰。Mac Safari 支持触控板双指旋转；其他 Mac 浏览器可用 Option + 双指滑动旋转。触屏保留原生双指操作，并提供 Q / E 和屏幕旋转按钮。浏览器与实机支持边界见 [STUDIO_08.md](docs/STUDIO_08.md)。

首页保留玄武区8个真实轮廓研究单元、2,697个周边设施参考点、五维评估、权重情景、2–3单元比较、来源对话、容量假设与含地图的DOCX报告。点击“开始完整演示”可顺序走通流程。

默认公共数据模式保留未知业务字段，不输出综合分。完整演示台账使用明确标识的虚构属性，仅用于演示更新研究关注度，不代表真实土地价格或项目可实施性。研究轮廓不是登记宗地或官方更新范围。

使用 `npm ci && npm run build` 构建，`npm start` 启动；`npm run check && npm test` 验证。发布仅使用 GitHub Pages。前端使用可检查的 UTF-8 JavaScript 分块；本阶段保留既有玄武区数据，六区扩展暂缓。最新功能与验收记录见 [LIQUID_10.md](docs/LIQUID_10.md)。云端浏览器不支持真实 GPU 渲染，相应三维视觉和硬件手势需要实机验证。

数据、功能边界和演示步骤见 [VALUE_STUDIO.md](docs/VALUE_STUDIO.md)，地图底座见 [XUANWU_DATA.md](docs/XUANWU_DATA.md)。此前12宗虚构地块及旧交互保留在 `demo.html`。DeepSeek暂缓；首页对话使用本机确定性检索和来源解释。报告、评估、对话历史和保存的视角均保存在当前浏览器。

# UrbanLens

**城市更新用地智能评估交互系统**  
Land Intelligence for Urban Renewal

[打开 GitHub Pages 工作台](https://zipan07.github.io/UrbanLens/)

### Metro 05 · Metropolitan Intelligence

保留深墨蓝、青柠与冷紫工作台，地图升级为浅色建筑场景：玻璃幕墙、住宅坡屋顶与阳台、砖墙厂房、屋面设备、桥梁、树冠及车辆尺度参照。支持自然材质、用地与高度三种外观，以及日间和暖阳照明。城市采用不规则街区和不同建筑朝向，含 3,528 栋模拟建筑、61片绿地以及曲流和湖区，面积约为前版4倍。所有城市模型均为程序化虚构模型，不是摄影测量或照片级复原。

UrbanLens 面向规划研究与城市更新评估工作，将地块档案、地图交互、多维评估和来源解释放在同一个工作台。本仓库从 V0.1 交互原型起步，逐步接入真实空间数据与后台能力。

## 当前版本

首轮原型使用 12 宗**虚构地块**与明确标识的 `DEMO-0.1` 演示规则。地图为 12 × 8.4 km 虚拟城市，以 Three.js / WebGL 绘制三维建筑与二维平面，具有光照、软阴影与深度遮挡；WebGL 不可用时回退到 Canvas 示意体量。建筑几何和高度独立于演示台账，不能据此计算容积率或评估分数。所有选择和计算仅存在于当前页面内存，刷新后重置。

已实现：

- 2D / 3D 同位置切换，平移、缩放、旋转、全城总览及当前地块定位。
- 居住、商务、工业、公服建筑，以及水系、绿地、道路、桥梁、轨道和站点。
- 六类图层开关、用地 / 高度着色、背景建筑和设施属性查询、展开画布。

- 地图和列表双向选地，编号、名称、用途、面积范围、评估状态和指标完整性联合筛选（F02）。
- 地块详情关联模拟建筑，显示指标缺失和规划、权属、安全资料待核实清单（F02 / F03）。
- 高清 / 流畅画质；导出长边目标 3840 px 的地图 PNG，并附数据标识、图例说明、比例尺与北向。实际尺寸受设备限制；兼容模式最多 4 倍采样。该导出尚未自动嵌入正式报告（F06 部分）。
- 地块基本档案、单地块五维规则计算和来源查看。
- 区分真实零值、资料缺失和不可计算；数据不完整时不输出综合分。
- 2–3 宗地块同口径比较。
- 基于平台语料的带来源检索回答，支持当前地块/比较清单/项目范围与独立会话历史。\n- 已提供 DeepSeek 服务端代理与前端连接界面；**尚未部署后端或配置真实密钥，默认未调用模型**。部署方法见 [DEEPSEEK.md](docs/DEEPSEEK.md)。\n- 会话内评估运行编号、时间和输入/结果快照，报告关联运行。
- 当前地块评估摘要、Markdown 下载及浏览器打印 / PDF。
- 键盘选地、响应式布局及标准浏览器不支持 WebMCP 时的正常降级。

尚未实现：真实底图 / GIS 导入、服务器持久化、账号权限、真实政策知识库、DeepSeek真实部署联调、正式评估规则、DOCX 报告和复核历史。不得将此原型作为完整 PRD 已交付或真实决策系统。

## 本地运行

使用 Node.js 22 或更高版本。依赖版本已锁定；Three.js 被打包到站点，不依赖外部 CDN。修改三维场景后必须重新构建：

```sh
npm ci
npm run build
npm start
```

打开终端显示的本机地址。不要以 `file://` 方式直接打开页面，浏览器 ES 模块需要 HTTP 服务。

```sh
npm test
npm run check
```

22 项测试覆盖评分、缺失值、合法0值、筛选、报告一致性、城市几何、相机正逆变换、三维与二维标签对齐、建筑实例矩阵及兼容绘制调用。未验证真实 GPU 着色器执行、浏览器视觉、PNG 下载或端到端交互；自动测试通过不等于完成这些验收。

## 目录

- `dist/`：可独立托管的前端与已构建静态资产。
- `src/city-webgl.js`：三维场景源代码，构建产物为 `dist/scene.js`。
- `dist/domain.js`：演示地块、计算口径、解释与摘要逻辑。
- `dist/app.js`：界面状态、地图联动、比较及报告交互。
- `dist/city-data.js`：可重复生成的虚构城市与投影数学。
- `dist/city-view.js`：三维体量绘制、图层、相机操作和空间拾取。
- `docs/PRD-v0.1.md`：产品需求评审基线，不代表全部实现。
- `docs/ROADMAP.md`：本轮范围、下一步与验收说明。
- `test/`：使用 Node 内置测试工具的领域逻辑测试。

## 开发约定

通过功能分支与 Pull Request 评审，避免直接修改主分支。真实数据、API 密钥及环境配置不提交到仓库。先冻结数据与评估规则，再接入真实 GIS / AI 服务。演示规则和真实规则必须分开管理。

## 城市探索操作

拖动平移，双指同时旋转/缩放/平移；桌面滚轮缩放、Shift / 右键拖动旋转；地图聚焦后可用方向键平移、加减键缩放、R 恢复全城。点击更新地块进入原有评估流程；点击其他建筑或设施查看虚构属性。列表搜索只覆盖 12 宗更新地块，城市背景不会被当成可评估地块。

交互参考：[TestFit](https://www.testfit.io/) 的三维环境与地块尺度操作、[UrbanFootprint Base Canvas](https://urbanfootprint.com/video/what-is-the-base-canvas/) 的城市底层空间组织，以及 [LightBox Vision](https://www.lightboxre.com/data/lightbox-vision/) 的地块与建筑图层。当前是独立实现的体量浏览原型，不包含这些产品的真实数据库、生成式规划或商业分析能力。

Atlas 06 图形兼容：支持图形加速时使用 MapLibre 2D / 3D 与真实地形；不可用时自动进入同数据的 Canvas 2D 模式。桌面与390px窄屏页面、搜索、档案、导入/移除已线上检查。当前测试浏览器禁用GPU，真实城区3D的实机视觉验收尚未完成；验证边界详见 XUANWU_DATA.md。
